# eikenreading

英検Reading教材生成用のプロンプト・品質管理ルールを管理する専用リポジトリです。

## Canonical source

- `MASTER_PROMPT.md` : このリポジトリで最優先する統合マスタープロンプト
- `rules/FAMOUS_EPISODE_POLICY.md` : 作品題材で「実際の有名エピソード」を必須にするルール
- `rules/NATURAL_JAPANESE_TRANSLATION.md` : 全文和訳の自然さを保証するルール

## 運用

この「英検面白問題✨」プロジェクトで、英検Reading教材の作問・出力・QAルールに修正が入った場合は、以後このリポジトリを更新対象とする。

特に作品・アニメ・漫画を題材にする場合は、作品名だけを借りた一般論ではなく、原作・本編・公式情報で確認できる代表的なエピソードを本文設計の中心に置く。ただしファンクイズ化はせず、本文だけで解答できるReading問題として自立させる。

日本語訳は、原文の意味を保持しながら、日本語として読みやすく自然な文章にする。英語語順をそのまま移した機械翻訳調は不可。
