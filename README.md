# eikenreading

英検Reading教材生成用のプロンプト・品質管理ルールを管理する専用リポジトリです。

## 必須の参照順

1. [MASTER_PROMPT.md](MASTER_PROMPT.md)：作問・題材・解説・和訳・出力全体の統合指示。
2. [LAYOUT_MASTER_PROMPT.md](LAYOUT_MASTER_PROMPT.md)：内容確定後に必ず実行する最終組版・Word/PDF変換・文字照合・全ページ画像確認の指示。
3. 2級では [references/EIKEN_G2_LAYOUT_REFERENCE.md](references/EIKEN_G2_LAYOUT_REFERENCE.md)：公式問題の参照URLとページ、パート別の配置、過去の組版不良と再発防止例。
4. [rules/FAMOUS_EPISODE_POLICY.md](rules/FAMOUS_EPISODE_POLICY.md)：作品題材で実際の有名エピソードを扱うルール。
5. [rules/NATURAL_JAPANESE_TRANSLATION.md](rules/NATURAL_JAPANESE_TRANSLATION.md)：自然な全文和訳のルール。

関連ファイルは冒頭の断片だけでなく全文を読む。最終組版を任意の付録扱いにしない。内容品質はMASTER_PROMPT、レイアウト・出力検査の詳細はLAYOUT_MASTER_PROMPTに従う。

## 標準の制作工程

**公式資料の確認 → 作問・事実確認 → 内容データの確定 → 本番のパート別レイアウトへ組版 → 最終WordからPDFへ変換 → 出力実測・日本語全文照合・全ページ個別画像確認 → 納品**

内容が正しくても、用紙・書体・改ページ・漢字表示が不良なら完成ではない。問題冊子をWord既定の青見出し、Letter用紙、小さいArial本文で出力しない。大問1の選択肢配置、大問2の長文ごとのページ、大問3Aのメール枠、大問3Bの本文と5設問のページを、公式参照に合わせる。

数値やフォント名は、公式資料から確認したものと再現用の設定値を区別する。実行していない検査を「確認済み」と報告しない。

## 運用

この「英検面白問題✨」プロジェクトで、英検Reading教材の作問・出力・QAルールに修正が入った場合は、以後このリポジトリを更新対象とする。

特に作品・アニメ・漫画を題材にする場合は、作品名だけを借りた一般論ではなく、原作・本編・公式情報で確認できる代表的なエピソードを本文設計の中心に置く。ただしファンクイズ化はせず、本文だけで解答できるReading問題として自立させる。

日本語訳は、原文の意味を保持しながら、日本語として読みやすく自然な文章にする。英語語順をそのまま移した機械翻訳調は不可。元の文章が正しくてもPDF変換で文字が欠落すれば不合格とする。

完成教材は原則Word＋PDF。テーマ紹介と問題部分、語彙、解答解説を整理し、全文和訳を最後に置く。内部検査表や制作メモは生徒用教材には載せない。
