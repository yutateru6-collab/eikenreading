## 最初に読む：全指示の理解・実装・検証

**[AGENTS.md](AGENTS.md) を最初に全文読む。関連指示をすべて最後まで読み、各要件の意味・適用範囲・実装方法・検証方法を把握するまで、教材の文章や生成コードを書き始めない。適用される必須要件はすべて守り、違反・未確認が一件でも残る教材を完成版として納品しない。**

「読んだ」「理解した」という自己申告では通過できない。AGENTS.mdの読了記録、全要件の対応表、実装、最終ファイルの検証を実行する。指示にない自己都合の省略や基準の緩和をしない。記録は作業用とし、生徒用教材へ載せない。

## 標準の制作工程

**全指示の全文取得・読了と公式資料の確認 → 全要件の解釈・実装先・検証方法の対応づけ → 作問・事実確認 → 内容データの確定 → 本番のパート別レイアウトへ組版 → 最終WordからPDFへ変換 → 出力実測・日本語全文照合・全ページ個別画像確認 → 全適用要件の合格を確認して納品**

内容が正しくても、用紙・書体・改ページ・漢字表示が不良なら完成ではない。問題冊子をWord既定の青見出し、Letter用紙、小さいArial本文で出力しない。大問1の選択肢配置、大問2の長文ごとのページ、大問3Aのメール枠、大問3Bの本文と5設問のページを、公式参照に合わせる。

数値やフォント名は、公式資料から確認したものと再現用の設定値を区別する。実行していない検査を「確認済み」と報告しない。実装済みと検証済みを区別し、証拠のない項目は未確認として扱う。最終ファイルを変更したら、古いPDF・画像・依存する検査結果を無効化し、再生成・再検査する。

## 運用

この「英検面白問題✨」プロジェクトで、英検Reading教材の作問・出力・QAルールに修正が入った場合は、以後このリポジトリを更新対象とする。

特に作品・アニメ・漫画を題材にする場合は、作品名だけを借りた一般論ではなく、原作・本編・公式情報で確認できる代表的なエピソードを本文設計の中心に置く。ただしファンクイズ化はせず、本文だけで解答できるReading問題として自立させる。

日本語訳は、原文の意味を保持しながら、日本語として読みやすく自然な文章にする。英語語順をそのまま移した機械翻訳調は不可。元の文章が正しくてもPDF変換で文字が欠落すれば不合格とする。

完成教材は原則Word＋PDF。テーマ紹介と問題部分、語彙、解答解説を整理し、全文和訳を最後に置く。内部検査表や制作メモは生徒用教材には載せない。
